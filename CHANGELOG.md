## [0.1.0]

A quieter beginning for Windows: Lineup gives the programs that greet each session a clear place in the score, with JSON plans you can read before anything changes.

### Features

- Inspect startup entries and check for missing targets and duplicates.
- Plan and apply JSON manifests, or remove and run individual entries.
- Manage current-user and machine startup entries, including delayed and elevated tasks.
- Return structured JSON for scripts and coding agents.
